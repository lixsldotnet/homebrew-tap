# Homebrew tap

Apps and tools by lixsl for macOS on Apple silicon.

| Name | What | Website |
|---|---|---|
| `geist` | Geist, being rebuilt as Geist 3. Disabled for now, there is no download. If you still have Geist 2 installed, `brew uninstall geist` and removing `~/.geist` removes it all. | https://getgeist.dev |

The formula is written by the project's release script, the download and its SHA-256
checksum come from the project's website.
