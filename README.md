# Homebrew tap

Apps and tools by lixsl for macOS on Apple silicon.

| Name | What | Website |
|---|---|---|
| `geist` | Geist, a coding agent for the terminal that runs local MLX models on your Mac. `brew install lixsldotnet/tap/geist` | https://getgeist.dev |

The formula is written by the project's release script, the download and its SHA-256
checksum come from the project's website.

Geist 3 (the desktop app, a cask) is no longer published here. If you have it installed:
`brew uninstall --cask geist`.
